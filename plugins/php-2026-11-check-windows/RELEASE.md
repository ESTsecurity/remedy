# php-2026-11-check-windows — 릴리스 기록

**버전 0.1.0** · 대상: PHP 2026년 11월 보안 업데이트(8.5.13 · 8.4.28 · 8.3.37 · 8.2.36)가 고친 결함 18건(CVE-2026-129474 등) —
Windows · **점검**(바꾸지 않는다)

## 0.1.0 — 2차 (2026-11-20)

긴급 경로의 2차다 — 1차(`php-2026-11-check-linux` 0.1.0 · `rules-2026.11.20`)가 리눅스를 냈고 이 룰이 Windows 를 더한다(코어
그대로). 영향 판 · 고친 판 · 결함마다의 조건 · 출처는 리눅스 룰의 `RELEASE.md` 와 같다 — 여기서 되풀이하지 않는다(Windows
꾸러미에는 그 파일이 없다 — https://github.com/ESTsecurity/remedy/blob/main/plugins/php-2026-11-check-linux/RELEASE.md).
`added: "2026-11-20"`.

### 판정

| 무엇 | 결과 |
|---|---|
| 설치본(코어 DLL `php8ts.dll` · `php8.dll` · … 가 있는 폴더 — `C:\php` · `Program Files\PHP` · XAMPP · WampServer · Laragon · Chocolatey)의 파일 버전이 그 갈래의 고친 판 아래 · 지원이 끝난 8.1 이하 | 취약(2) |
| 코어 DLL 에서 정식 판을 읽지 못했다(버전 정보 없음 · 시험판 `8.6.0RC3` · 개발 빌드 `8.6.0-dev`) | 확인 필요(6) |
| 위 자리 밖의 PHP 를 IIS 가 쓰거나 서비스(NSSM 포함) · Apache 설정이 싣거나 그 PHP 가 실행 중 · 다른 프로그램에 모듈로 실림 · 모듈 목록을 읽지 못한 Apache · IIS 공유 설정 | 확인 필요(6) |
| 그 갈래의 고친 판 이상 · 정식 8.6 이상 · PHP 없음 | 0 |

- **판으로만 판정한다**(1차 카드와 같은 정책) — PHP2Shell 룰(`php2shell-check-windows`)은 공식 빌드의 해시로 확정했지만 이
  룰은 판 번호를 따른다. Windows 의 PHP 는 배포판 백포트가 없고, 공식 빌드는 상류 판을 파일 버전에 그대로 적는다.
- **판은 코어 DLL 의 파일 버전 자원이다** — 판마다 하위 폴더를 두는 WampServer · Laragon · `Program Files\PHP\v8.3` 도 그대로
  읽는다(내용을 담지 않으므로 리눅스 룰의 글롭 한계가 없다).
- **설치본마다 가른다** — 고친 판과 영향 판이 함께 깔리면 영향 판 때문에 2, 판을 읽지 못한 설치본이 있으면 6 이다. 판 사실은
  그 설치본의 코어 DLL 하나에만 묶는다(`path equals ${core.file}`) — `from: ${core.dir}` 은 폴더 아래를 끝까지 걸어, 묶지
  않으면 설치본 폴더 안의 다른 설치본(옛 판 백업)이 바깥의 '판 없음' 을 채우고(0) 같은 영향 판을 두 번 셌다(취약 2건).
- **시험판 · 개발 빌드는 6** — 공식 Windows 빌드의 코어 DLL 은 FileVersion 에 PHP_VERSION 을 그대로 넣어 시험판은 `8.6.0RC3`
  꼴이다. '판을 읽었다' 를 정식 판(끝을 묶은 `x.y.z` · `x.y.z.w`)으로만 쳐서, 8.6 시험판이 갈래 정규식에 걸리지 않고 0 으로
  끝나던 것을 막는다(8.2 ~ 8.5 의 시험판은 전부터 `version_lt` 가 꼬리를 거절해 6 이었다).
- **파일은 PHP 자리만 걷는다**(`subject_roots.file`) — WampServer 는 Apache 모듈로 쓰는 PHP 의 코어 DLL 을 Apache bin 에
  심볼릭 링크로 둔다. Apache 설정 자리(`C:\wamp64\bin\apache` 등)까지 파일로 걸으면 그 링크(판 없음)가 설치본으로 세어져,
  PHP 를 고친 판으로 올린 WampServer 기계도 6 으로 끝났다. 같은 동작이 `php2shell-check-windows` 0.4.1 에도 있다(아래 후보).
- 위 셋은 1회차 뒤 독립 검토(관점 셋 · 반박 검증)가 찾았고 합성 스냅샷 · 랩 하네스로 고쳐진 것을 쟀다.
- **이 하네스가 재지 않는 줄** — 8.1 이하 갈래(공식 해시를 대조할 빌드가 없다) · 자리 밖 줄 가운데 IIS 설정 · 실린 모듈 ·
  모듈 목록을 읽지 못한 Apache · Apache 설정(PHP2Shell 룰 0.4.1 의 줄 그대로 — 그 룰의 rc A/B 스크립트 `Invoke-AbOutside` ·
  `Invoke-AbModules` · `Invoke-AbNssm` 이 잰다).
- 고친 Windows 빌드는 2026-11-19 에 상류와 같은 판으로 나왔다(downloads.php.net/~windows/releases — TS · NTS · 2026-11-19
  23:55 KST 확인).
