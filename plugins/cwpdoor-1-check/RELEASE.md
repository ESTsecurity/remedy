# cwpdoor-1-check — 릴리스 기록

**버전 0.1.0** · 대상: CWPdoor — 백도어를 심은 `cwpsrv`(Control Web Panel 의 패널 웹 서버) · 리눅스

> 출시 게이트(설계-03 §10) 기록이다. **찾기만 한다** — 치료는 같은 꾸러미의 `cwpdoor-2-clean` 이
> 한다. 판정 · 지표 · 쓰지 않는 것 · 실물 측정은 그쪽 `RELEASE.md` 와 같다.

## 무엇을 하나

- **판정** — `cwpdoor-2-clean` 과 같다(활성화 헤더 셋 and 0x55 XOR 된 공격자 공개키).
- **바꾸지 않는다** — `remediate` 가 없다. 화면은 *"위협 발견, 치료하지 않았습니다."* 다.
- **`kind: check` 가 아니다** — 그 선언은 취약한 *상태* 용이라, 감염에 붙이면 화면이 백도어를
  "취약" 이라고 부른다(`docs/plugin-guide/24-check-plugins.md`).
