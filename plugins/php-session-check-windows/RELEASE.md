# php-session-check-windows — 릴리스 기록

**버전 0.4.0** · 대상: PHP 세션 업로드 진행 설정(CVE-2026-115560 · php.net 2026-10-23 공지) — Windows · **점검**(바꾸지 않는다)

## 0.4.0 — NSSM 이 감싸 띄우는 PHP (2026-11)

`php2shell-check-windows` 0.4.0 과 같은 규칙 — NSSM(srvany)으로 등록한 서비스의 `Parameters\Application` 이 선언한 자리
밖의 PHP 면 **확인 필요(6)** 로 낸다. 그 PHP 의 설정은 열지 않는다. 코어 1.10.0 이 필요하다.

## 0.3.0 — 다른 프로그램에 모듈로 실린 PHP (2026-11)

`php2shell-check-windows` 0.3.0 과 같은 네 규칙을 더했다 — 다른 프로그램(Apache 등)에 모듈로 실린 선언 밖의 PHP 는
그 프로그램의 경로와 걸린 DLL 을 적어 **확인 필요(6)** 로, 모듈 목록을 읽지 못한 Apache(`httpd.exe`)도 확인 필요로
낸다. 멈춰 있어도 남는 자리 — 선언 밖의 PHP 를 띄우는 **서비스**와 그 PHP 를 싣는 **Apache 설정**의 `LoadModule` 줄 —
도 같다. 그 PHP 의 설정은 열지 않는다. 코어 1.9.0 부터 Windows 도 실린 모듈을 모은다.

## 0.2.1 — 화면 문구 (2026-11)

판정은 0.2.0 과 같다. 사유가 경로를 *위 경로* 로 가리키고(항목 줄이 주의 줄보다 위에 선다), *끈 설정이
있습니다* · *설정을 찾지 못했습니다* · IIS 공유 설정 사유에 다음 할 일을 붙였다.

## 0.2.0 — 선언한 자리 밖의 PHP 를 알린다 (2026-11)

`php2shell-check-windows` 0.2.0 과 같은 세 규칙(IIS 의 FastCGI · 처리기 · 공유 설정, 실행 중인 `php.exe` ·
`php-cgi.exe` · `php-win.exe`)으로 선언한 자리 밖의 PHP 를 찾아 그 경로를 적고 **확인 필요(6)** 로 낸다. 그 PHP 의
`php.ini` 는 열지 않는다. 코어 1.6.0 이 필요하다.

## 0.1.0 — 처음 (2026-11)

PHP 가 있으면 늘 확인 필요로 내고, 까닭을 설정 상태로 가른다. 코어 1.3.0 의 `verdict.unconfirmed` 를 쓴다.

## 무엇을 하나

- **판정(2)을 세우지 않는다.** 공지는 고친 버전을 내지 않았고(다음 정기 버전), 위험은 세 조건이 겹칠 때뿐이다 —
  `session.upload_progress.enabled` 가 켜져 있고, 서버의 `session.serialize_handler` 가 `php_binary` ·
  `php_serialize` 이며, 앱이 `session_start()` 전에 `ini_set()` 으로 그것을 `php` 로 바꾼다. 셋째는 앱 코드다.
- PHP(코어 DLL)가 있으면 **확인 필요(6)** — `php.ini` 의 설정이 켜짐 · 꺼짐 · 없음(기본값은 켜짐)에 따라 할 일을
  갈라 적는다. WampServer 의 Apache 가 읽는 `php.ini`(`C:\wamp64\bin\apache\…\bin`)도 본다. PHP 가 없으면 **해당 없음(0)**.

## 결과 읽기

| 종료 코드 | 뜻 |
|---|---|
| 0 | PHP 를 찾지 못했다 — 선언한 자리에도, IIS 설정에도, 실행 중인 프로세스에도(선언한 자리 밖에 두기만 한 PHP 는 보지 않는다) |
| 6 | **확인 필요** — 앱이 실행 중에 handler 를 바꾸면 `session.upload_progress.enabled=0` 으로 두고 웹 서버와 PHP 를 다시 시작한다(공지). 선언한 자리 밖의 PHP 면 항목 줄의 그 경로의 설정을 확인한다 — 다른 프로그램에 실린 PHP 면 괄호 안의 DLL 이 있는 폴더의 PHP 다(코어 1.9.0) |

## 이 룰이 보지 않는 것

- 실행 중인 PHP 에 반영된 값 · IIS 의 FastCGI 인자(`-d`)와 환경 변수(`PHPRC`) · 앱의 `ini_set()` · 선언한 자리 밖의 설정 파일.
- IIS 설정에도 없고 실행 중도 아니며 어디에도 실리지 않은, 선언한 자리 밖의 PHP · NSSM · srvany 밖의 감싸는
  프로그램이 띄우는 PHP(실행 중일 때만 본다).

## 서명 — 저장소 사본은 개발용 키, 배포본은 배포 키

저장소의 `MANIFEST` · `MANIFEST.minisig` 는 저장소 사본을 확인하려고 **개발용 키로** 서명한 것이다. 배포본은
태그의 배포 잡이 배포 키로 다시 서명하고 그 공개키를 박아 빌드하므로, 내려받은 배포 파일에 든 이 폴더는 배포
키의 서명이다(`plugin verify` 로 확인한다). 개발용 키로 서명된 룰은 배포 앵커가 박힌 실행 파일에서 거부된다.
