# php2shell-check-windows — 릴리스 기록

**버전 0.1.0** · 대상: PHP2Shell(CVE-2026-109618 · CVE-2026-109619) — Windows 의 PHP · **점검**(바꾸지 않는다)

## 0.1.0 — 처음 (2026-11)

설치본마다 공식 빌드 해시로 판정하고, 그 밖은 확인 필요로 낸다. 코어 1.3.0 의 `verdict.unconfirmed` 를 쓴다.

## 무엇을 하나

- **판정의 단위는 설치본**(코어 DLL `php8ts.dll` · `php8.dll` · `php7ts.dll` · … 이 있는 폴더)이다 — 한 기계에
  여럿 깔려도 한 설치본의 사실이 다른 설치본의 판정을 바꾸지 않는다.
- **공식 빌드 해시와 맞으면** 그 판이 판정이다 — 8.3.35(TS · NTS) → **취약(2)** · 8.3.36 → 0.
- **맞지 않으면 확인 필요(6)** 다 — PE 의 판 문자열은 그 빌드가 패치를 담았는지 말해 주지 않는다(같은 판
  번호로 다시 지은 빌드 · 공급사 빌드 · 직접 지은 빌드가 같은 문자열을 낸다). 판이 수정 판보다 낮거나 수정 판이
  없는 계열(5.4~8.1)이면 *패치되지 않았을 가능성이 큽니다* 를, 수정 판 이상이면 *받은 곳을 확인하십시오* 를 적는다.
- 확장 DLL(`ext\php_*.dll`)은 PHP 로 세지 않는다 — PHP 와 같은 판을 선언하지만 PHP 가 아니다.

## 결과 읽기

| 종료 코드 | 뜻 |
|---|---|
| 2 | **취약** — 공식 8.3.35 빌드다. 8.3.36 이상으로 올리고 IIS · Apache · PHP 를 다시 시작한다 |
| 0 | 취약한 곳을 찾지 못했다 — 공식 고친 빌드이거나, 선언한 자리에 PHP 가 없다 |
| 6 | **확인 필요** — `주의:` 아래 줄이 판을 올릴지(낮은 판) 받은 곳을 확인할지(높은 판) 말한다 |

## 이 룰이 보지 않는 것

- 선언한 자리(`C:\php` · `Program Files\PHP` · XAMPP · WampServer · Laragon · Chocolatey 의 `C:\tools\phpNN`) 밖의 PHP.
- 실행 중인 PHP 가 고친 판을 실었는가 — 고친 뒤에는 IIS · Apache · PHP 를 다시 시작한다.
- php.net 의 2026-10-26 Windows 재빌드(`8.x.y-1` · Brotli — CVE-2026-111497)는 이 룰의 판정이 아니다. PHP 판
  번호가 그대로라 재빌드인지는 해시로만 가린다 — 그 해시가 목록에 없으면 이 룰은 *확인 필요* 로 낸다.

## 근거 — 공개 공지와 공식 빌드

- 상류 수정 판 8.2.35 · 8.3.36 · 8.4.27 · 8.5.12 — php.net 2026-10-21 보안 공지(8.1 이하는 고친 판이 없다)
- 공식 빌드 해시 — downloads.php.net 의 `php-8.3.35` · `php-8.3.36` Windows x64(TS · NTS) 코어 DLL
