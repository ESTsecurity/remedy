# node2shell-check-windows — 릴리스 기록

**버전 0.1.0** · 대상: Node2Shell(CVE-2026-111497 · Brotli 디코더) — Windows 의 Node.js 와 PHP for Windows 의 Brotli · **점검**(바꾸지 않는다)

## 0.1.0 — 처음 (2026-11)

공식 빌드의 해시로만 판정하고, 그 밖은 확인 필요로 낸다. 코어 1.3.0 의 `verdict.unconfirmed` 와 `hash_large`
(83~90 MiB 인 공식 `node.exe` 를 흘려 읽어 해시)를 쓴다.

## 무엇을 하나

- **Node.js** — `node.exe` 가 공식 빌드(win-x64 89판)의 해시와 맞으면 그 판이 판정이다. 22 · 24 · 26 계열은 고친 판
  (22.23.4 · 24.22.1 · 26.12.1) 미만이면 **취약(2)**, 지원이 끝난 18.20.8 · 20.20.2 는 든 Brotli(1.1.0)가 영향 범위라
  **취약(2)**. 맞지 않으면(기준에 없는 판 · 다른 빌드 · 읽지 못함) **확인 필요(6)**.
- **PHP for Windows 의 Brotli** — PHP 폴더의 `brotlidec.dll` 이 2026-10-26 재빌드(`-1` · Brotli 1.2.1) 전의 공식
  빌드(Brotli 1.2.0)이면 **취약(2)**, 재빌드면 0, 맞지 않으면 **확인 필요(6)**. 파일에 판 정보가 없어 해시로만 가린다.
- 자리: 공식 설치 관리자(`Program Files\nodejs`) · 사용자마다의 nvm-windows · fnm · Volta · nvm(`%ALLUSERPROFILES%` —
  모든 사용자), PHP 는 `php2shell-check-windows` 와 같은 자리.

## 결과 읽기

| 종료 코드 | 뜻 |
|---|---|
| 2 | **취약** — Node.js 를 고친 판 이상으로, PHP 는 2026-10-26 이후의 공식 빌드(`-1` 재빌드)로 바꾸고 그 서비스를 다시 시작한다 |
| 0 | 취약한 곳을 찾지 못했다 — 공식 고친 빌드이거나, 선언한 자리에 Node.js · PHP 가 없다 |
| 6 | **확인 필요** — `주의:` 아래 줄이 무엇의 판 · 받은 곳을 확인할지 말한다 |

## 이 룰이 보지 않는 것

- 다른 제품 안에 든 Node.js(Electron 앱 · 단일 실행 파일) · 선언한 자리 밖의 `node.exe` · `brotlidec.dll`.
- 실행 중인 프로세스가 고친 판을 실었는가 — 고친 뒤에는 그 서비스를 다시 시작한다.

## 근거 — 공개 자료

- CVE-2026-111497(CNA Google) — Brotli 1.0.3~1.0.10 미만 · 1.1.0~1.1.1 미만 · 1.2.0~1.2.1 미만이 영향 범위
- Node.js 2026-10 보안 릴리스 — 22.23.4 · 24.22.1 · 26.12.1
- Node 공식 해시 — nodejs.org 의 서명한 SHASUMS256 의 win-x64 `node.exe` 89판. 값마다 룰에 판을 적었다
- PHP for Windows — downloads.php.net 의 8.2.35 · 8.3.36 · 8.4.27 · 8.5.12 원래 빌드와 `-1` 재빌드 ZIP(TS · NTS).
  각 ZIP 의 SHA-256 을 같은 자리의 SBOM(`.cdx.json`)과 맞췄고, SBOM 이 Brotli 판(1.2.0 → 1.2.1)을 적는다. 같은 빌드
  도구 묶음(vs16: 8.2 · 8.3 / vs17: 8.4 · 8.5)은 같은 `brotlidec.dll` 을 낸다(2026-11-09 실측)
