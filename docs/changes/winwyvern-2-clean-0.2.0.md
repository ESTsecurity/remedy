* **WinWyvern 제거 — 다시 시작해야 끝나는 치료 알리기 · 그 상태의 복원 멈추기** (Windows)\
  판정과 치료(서비스 `NeacSafe64` 를 멈추고 지우기)는 그대로이고, 프로그램 1.26.0 이상에서 돕니다. Windows 가 그 서비스 지우기를 미루면(그 서비스를 열어 둔 프로그램이 있었거나 메모리에 실린 드라이버라 멈추지 못했을 때) 치료 화면이 *일부 항목은 다음 부팅에 사라집니다* 아래에 그 서비스를 *Windows 가 지우기를 미뤘습니다. PC 를 다시 시작하면 지워집니다* 로 적고, 다시 시작하기 전의 복원은 아무것도 쓰지 않고 멈춥니다. 이전 버전은 같은 치료를 *치료 완료* 로만 알렸고, 그 상태에서 복원하면 Windows 가 복원한 등록까지 지울 수 있었습니다.

<details><summary><b>알아두실 점 및 자세한 내용 보기</b></summary>

* 멈추지 못한 드라이버도 같은 치료에서 사용 안 함이 끝났으면 *드라이버가 정지를 받지 않았습니다. 비활성화해 두었으므로 PC 를 다시 시작하면 올라오지 않습니다* 로 알리고 *치료 완료* 로 끝냅니다(이전 버전은 *일부 실패*). 치료가 끝나면 이전처럼 화면을 담당자에게 보낸 뒤 PC 를 다시 시작하고 관리자 계정으로 로그온합니다.
* 정상 설치를 지웠다고 판단되면 이전처럼 PC 를 먼저 다시 시작한 뒤 치료 전으로 복원하고, 한 번 더 다시 시작합니다.
* 치료한 뒤 *위협 없음* 이어도 대체 데이터 스트림에 숨긴 악성 DLL 은 남습니다 — 이전과 같습니다(위협별 안내의 *꼭 할 일*).

</details>
