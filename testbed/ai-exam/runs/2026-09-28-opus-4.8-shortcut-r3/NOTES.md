| 지문 | 코드 | 설명 | 출처 |

| 여기가 아니라 `remove` 다 | 0 | 0 | `22-remediate` `edit` 절 (`8894b21`) |
| **인자만** | **2** | **2** | 같은 새 문장 — 꾸러미에서 이 한 곳 · 위협 0 |
| r1 의 지문 일곱 | 0 | 0 | `22-remediate` · `32-lint-errors` |

넷 가운데 **셋이 치료 문맥이고 새 문장과 같은 모양이다** — 주석 *"ref →
shortcut.strip_args. **인자만 뗀다** — 파일도 가리키는 곳도 남는다"*, 설명 *"치료는
바로가기의 인자만 떼고"* · *"인자만 떼고 `.lnk` 파일과 가리키는 chrome.exe 는 남긴다"*.
새 문장은 *"바로가기는 인자만 뗀다(`shortcut.strip_args` · 파일은 남는다)"* 다. 나머지
하나(*"덧붙은 인자만 본다"*)는 탐지 문맥이다. **사전에 정한 대로 새 문장을 읽은 쪽으로
적는다.** *"가리키는 곳"* 은 위협 설명의 요구 사항에서 왔다(r2 와 같다).

## r1 이 맞힌 셋 — 재현됐다

- **인자가 가리키는 곳으로 가른다.** *"인자의 유무로 가르지 않는다. 정상 Notepad.lnk 에도
  인자가 있다."* 실리는 확장이 `ProgramData` 아래인 것과 보호 기능을 끄는 것을 함께 본다.
- **이름이 닮은 이웃을 건드리지 않는다.** 파일 상한을 실리던 폴더로 좁히고
  `subject_roots` 로 한 번 더 가뒀다 — 이웃 도구는 남아야 하는 자리 3/3 에 들어 있다.
- **없는 것을 찾지 않는다.** *"설치된 확장 목록은 보지 않는다 — 이 검체는 확장을 설치하지
  않는다."*
