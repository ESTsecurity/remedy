## 2 회차와 무엇이 다른가

2 회차 답에 규칙 하나와 선언 하나를 더한 것뿐이다.

```yaml
- id: payload-file          # 경로로 매치되는 규칙 — 본문 없이도 선다
  subject: file
  from: "${task.dir}"
  where:
    - { field: path, op: ends_with, value: ".js" }

collect_extra:
  - { ref: payload-file, content: true }
```

**`ref` 가 `payload` 가 아니라 `payload-file` 인 것이 요점이다.** YARA 로만
정의된 규칙을 가리키면 순환이 된다 — 1 차 평가에서 본문이 없어 매치되지
않으므로 담을 것을 정하지 못한다 (`30-antipatterns.md` 1 번).

## 확인된 것

**린트를 고친 뒤에도 시험은 도달 가능하다.** 검사를 추가하면서 통과할 수 없는
문제로 만들어 버리지 않았다는 확인이다.

새 린트가 첫 플러그인(`plugins/evilai-locust`)을 오탐하지 않는 것도 함께
확인했다 — 그쪽은 `payload-file` 을 가리키는 `collect_extra` 를 이미 갖고 있다.

## 여전히 남는 것

**오염되지 않은 회차.** 1·2·3 회차 전부 같은 세션에서 저장소를 보며 쓴 것이라
모델 실측이 아니다. 이 셋이 실측한 것은 **시험 자체의 성립 여부**다.
