# 형식은 `ldso-preload/expected-ops.txt` 의 머리를 볼 것 — (Op, 대상) 이고
# `::` 뒤는 match 다. 셋 다 match 가 없다: 전부 자리가 통째로 없어지는 Op 이다.
#
# **이 목록은 정답 플러그인의 계획을 그대로 옮긴 것**이고(2026-09-09, 개발 PC 의
# `evaluate` → `plan`), 사람이 한 줄씩 위협 설명과 맞춰 읽었다.
#
# # 이 위협이 재는 것은 여기 **없는** 줄이다
#
# 같은 폴더의 `notes.txt` 와 같은 모양의 `vendor-update.desktop` 이 여기 없다.
# 자리·모양·"서버 주소가 있다" 로 가른 답안은 그 둘을 함께 지우고, 그러면
# 계획이 이 목록보다 길어져 떨어진다(`extra`). 목록(해시·도메인)으로만 가른
# 답안이 정확히 이 셋을 낸다.
#
# 자동 시작 항목은 파일 하나라 없애는 Op 도 하나다 — `.service` 였다면
# `persistence.disable → persistence.delete` 둘이었겠지만, 그것은 지표 원천이
# 아니라서 이 위협의 지속성으로 쓰지 않았다(픽스처 스크립트의 주석).
