## 관측 보고 — 검색을 가로채는 광고 임플란트

감염된 Windows 10 기계를 확보해 다음을 관측했다.

### 페이로드

`C:\ProgramData\WebBoost\` 안에 두 파일이 있다.

```
wbsvc.exe     1,245,184 바이트    상주하며 광고를 받아 온다
wbboot.exe      172,032 바이트    부팅 때 나머지를 되살린다
```

### 브라우저 확장 — 같은 것이 두 브라우저에

Chrome 과 Edge 의 기본 프로필 **양쪽에** 같은 확장이 설치돼 있다.

```
식별자   pknbjlbmgcodmfilnjadgpkcnkmlpkkn
이름     WebBoost Search
판       3.2.0
```

**이 기계에는 정상 확장도 함께 있다.**

```
chrome   ghbmnnjooekpmoecnnnilnnbdlolhkhi   판 1.109.1
edge     jmjflgjpcpepeafmmgdpfkogkghcpiha   판 1.2.1
```

> 브라우저 이름이나 프로필 이름으로 고르면 **정상 확장이 함께 없어진다.**
> 청정 기계에도 이 자리에 확장 넷이 있고, 그중 하나는 두 브라우저에 같이
> 설치돼 있다.

### 실행 경로 앞자리를 차지했다

시스템의 실행 경로 목록 **맨 앞**에 페이로드 폴더가 끼어 있다.

```
C:\ProgramData\WebBoost;%SystemRoot%\system32;%SystemRoot%;
%SystemRoot%\System32\Wbem;%SYSTEMROOT%\System32\WindowsPowerShell\v1.0\;
%SYSTEMROOT%\System32\OpenSSH\
```

**첫 항목만 검체의 것이고 나머지는 이 기계가 원래 갖고 있던 것이다.**
목록을 통째로 비우면 그 기계는 명령 하나도 찾지 못한다.

### 부팅 목록에 한 줄이 덧붙었다

부팅 때 실행되는 목록에 항목 하나가 늘었다.

```
autocheck autochk *      ← Windows 자신의 것
                         ← 빈 항목
bootalyac.exe            ← 설치된 보안 제품의 것
                         ← 빈 항목
wbboot.exe               ← 검체가 넣었다
```

빈 줄은 오타가 아니다. **이 값에는 빈 항목이 섞여 있고 이 기계에 원래 그렇게
들어 있다** — 검체가 만든 것이 아니다.

> **가운데 줄을 지우면 안 된다.** 이 기계에 설치된 정상 보안 제품이 부팅
> 때 쓰는 항목이고, 청정 기계에도 그대로 있다. *"첫 줄 말고 다 지운다"* 는
> 판단은 그 제품을 망가뜨린다. **검체가 넣은 마지막 줄만 빼야 한다.**

### 프록시가 바뀌었다

사용자 프록시 설정이 검체 쪽을 가리킨다.

```
서버   127.0.0.1:8899
```

**정상 기계에서는 이 자리에 서버가 비어 있다.** 대신 예외 목록만 채워져
있는 것이 보통이다.

### 오탐 위험 — 반드시 읽을 것

**이 기계의 정상 항목들이 검체의 것과 같은 자리에 있다.**

- 같은 두 브라우저의 같은 프로필에 **정상 확장이 함께 산다.**
- 실행 경로 목록의 나머지 다섯 항목은 Windows 의 것이다.
- 부팅 목록의 앞 두 줄은 Windows 와 정상 보안 제품의 것이다.
- 프록시 설정 자체는 정상 기계에도 있다 — 자리가 아니라 **무엇을 가리키는지**로
  갈린다.

### 요구

이 검체를 탐지하고, **두 브라우저에서 그 확장을 빼고**, 실행 경로 목록에서
**끼어든 항목 하나만** 빼고, 부팅 목록에서 **덧붙은 줄 하나만** 빼고, 프록시를
되돌리고, 페이로드를 제거해야 한다. **원래 있던 것은 전부 남아 있어야 한다** —
정상 확장도, 경로 목록의 나머지도, 부팅 목록의 앞 두 줄도.
