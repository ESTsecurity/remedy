## 관측 보고 — 어디로 가는지가 두 군데에서 돌려져 있다

감염된 Windows 10 기계를 확보해 다음을 관측했다.

### 이름 풀이 파일에 줄 셋

`C:\Windows\System32\drivers\etc\hosts` 는 이름을 주소로 바꾸는 표다. 그
파일 끝에 줄 셋이 붙어 있다.

```
22번째 줄   192.168.10.14    buildserver buildserver.corp.example
23번째 줄   10.20.30.40      update.microsoft.com
24번째 줄   10.20.30.40      login.bank-example.co.kr
```

**첫 줄은 조직이 넣은 것이다.** 사내 빌드 서버를 사설 주소로 가리키는 흔한
설정이고 **남아야 한다.** 뒤의 둘은 같은 주소를 가리키는데, 하나는 운영체제
갱신 서버이고 하나는 은행 로그인 주소다.

앞의 스물한 줄은 운영체제가 처음부터 넣어 둔 주석이다. **이 파일을 통째로
치우면 그 스물한 줄과 조직의 줄이 함께 사라진다.**

### 나가는 길도 같은 주소를 거친다

```
프록시 서버   10.20.30.40:8080     ← 위 두 줄과 같은 주소다
프록시 사용   켜짐
```

**이 주소가 셋을 하나로 묶는다.** 이름 풀이를 돌려 그 주소로 보내고, 나가는
길도 그 주소를 거치게 했다.

### 페이로드와 다시 서는 자리

```
C:\ProgramData\NetOpt\netopt.exe                 ← 검체  (1,245,184 B)
C:\ProgramData\NetTools\latency-probe.exe        ← 정상. 남아야 한다  (331,776 B)
```

둘 다 `C:\ProgramData` 아래 있고 이름도 둘 다 네트워크 도구처럼 보인다.

로그온할 때 실행되는 항목 **열일곱** 중 하나가 검체의 것이다.

```
NetOptimizer    "C:\ProgramData\NetOpt\netopt.exe" /min
```

나머지 열여섯은 이 기계에 설치된 정상 소프트웨어의 것이고 **전부 남아야
한다.**

## 건드리지 않는 자리 — 프록시 사용 표시

검체가 **프록시 사용 표시**도 켜 두었다. 그런데 이 자리는 **그대로 두는 것이
맞다.** 까닭 둘:

1. 이 도구가 하는 모든 변경은 정해진 동작 목록 안에 있다. *"플래그를 0 으로
   쓴다"* 는 그 목록에 없는 임의 값 쓰기다.
2. **서버 주소가 사라지면 가로채기는 이미 멈춘다.** 켜짐 표시만 남은 것은
   무해하고, 원래 프록시를 쓰던 기계였다면 그 설정까지 지우는 쪽이 오히려
   피해다.

이 자리를 0 으로 쓰거나 지우는 답안은 **부수 피해**를 낸 것이다.

## 요구 사항

1. **돌려진 줄 둘만 뺀다.** 파일은 남아야 하고, 조직이 넣은 줄과 운영체제의
   주석도 남아야 한다.
2. **프록시 서버 주소를 원래대로 돌린다.**
3. **페이로드를 되돌릴 수 있게 치운다.**
4. **다시 서는 자리를 없앤다.** 남으면 다음 로그온에 돌아온다.
5. **프록시 사용 표시는 그대로 둔다.** 위 '건드리지 않는 자리'.
6. **정상 네트워크 도구와 정상 로그온 항목 열여섯은 그대로 둔다.**

## 이 위협이 재는 것

- **지우는 것과 되돌리는 것을 구별하는가.** 이름 풀이 줄과 프록시 주소는
  *"없앤다"* 가 아니라 *"원래대로 돌린다"* 다. 같은 결과처럼 보이지만 이
  도구는 둘을 다른 동작으로 다루고, 되돌리기 쪽만 원래 값이 무엇이었는지를
  본다.
- **한 파일 안에서 줄을 가르는가.** 같은 파일에 검체의 줄 둘과 조직의 줄
  하나와 운영체제의 주석 스물한 줄이 있다. 파일 단위로 다루면 반드시 남아야
  할 것이 사라진다.
- **무엇으로 가르는가.** 돌려진 두 줄은 이름이 서로 전혀 다르다 — 갱신
  서버와 은행. 공통점은 **같은 주소로 보낸다**는 것뿐이고, 그 주소가 프록시
  설정에도 있다.
- **할 수 있는 일의 경계를 아는가.** 프록시 사용 표시는 검체가 바꿨지만
  치료 대상이 아니다. *"검체가 바꾼 것은 전부 되돌린다"* 는 규칙은 여기서
  틀린다.
