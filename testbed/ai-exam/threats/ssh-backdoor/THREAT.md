## 관측 보고 — 원격 접속 문이 열려 있고, 지워도 10분 뒤 돌아온다

감염된 Debian 계열 기계를 확보해 다음을 관측했다.

### 원격 접속 설정 조각

SSH 서버는 `/etc/ssh/sshd_config.d/` 아래 조각들을 읽어 설정을 합친다. 거기에
조각 둘이 있다.

```
/etc/ssh/sshd_config.d/99-maint.conf            ← 검체가 만들었다  (107 B)
  2줄   PermitRootLogin yes
  3줄   PasswordAuthentication no
  4줄   AuthorizedKeysFile /etc/ssh/.maint/keys
```

```
/etc/ssh/sshd_config.d/10-hardening.conf        ← 정상. 남아야 한다  (77 B)
  2줄   PermitRootLogin no
  3줄   PasswordAuthentication no
  4줄   MaxAuthTries 3
```

**이름과 자리로는 가를 수 없다.** 둘 다 같은 폴더에 같은 확장자로 있고 이름도
그럴듯하다(`99-maint` · `10-hardening`). 그리고 **정상 조각을 없애면 그 기계의
접속 강화 설정이 풀린다.**

검체 조각이 지정한 열쇠 목록 파일이 실제로 있다.

```
/etc/ssh/.maint/keys                            ← 검체  (736 B)
```

폴더 이름이 점으로 시작해 목록에서 눈에 띄지 않는다.

### 10분마다 도는 정기 작업

`/etc/cron.d/` 에 정기 작업 정의 둘이 있다.

```
/etc/cron.d/ssh-maint                           ← 검체가 만들었다  (58 B)
  */10 * * * * root /usr/local/sbin/.sshd-maint --reinstall
```

```
/etc/cron.d/logrotate-custom                    ← 정상. 남아야 한다  (53 B)
  0 3 * * * root /usr/local/sbin/vendor-backup --daily
```

**같은 모양이다.** 같은 폴더, 같은 틀, 둘 다 `root` 로 돈다. 다른 것은
실행하는 것뿐이다.

배포가 심어 둔 정기 작업과 타이머도 **열넷** 함께 관측됐다(`e2scrub_all` ·
`apt-compat` · `dpkg` · `apt-daily` 계열 타이머 등). **전부 남아야 한다.**

### 페이로드

```
/usr/local/sbin/.sshd-maint                     ← 검체  (30,720 B)
```

```
/usr/local/sbin/vendor-backup                   ← 정상. 남아야 한다  (8,192 B)
```

### 이 기계가 하고 있던 일

정기 작업이 10분마다 페이로드를 부르고, 페이로드는 설정 조각과 열쇠 목록을
**다시 깐다**. 관리자가 조각을 지워도 10분 뒤 돌아오고, 그 사이 원격에서
관리자 권한으로 접속할 수 있다.

## 요구 사항

1. **다시 까는 자리를 없앤다.** 정기 작업이 남으면 나머지를 지워도 돌아온다.
   그 정의 파일은 통째로 검체가 만든 것이다 — 그 안의 줄 하나만 지우면 빈
   파일이 남는다.
2. **설정 조각을 통째로 치운다.** 한 줄만 빼면 관리자 접속 허용이 남는다.
3. **치운 것은 모두 되돌릴 수 있어야 한다.** 열쇠 목록과 페이로드도 같다.
4. **정상 조각·정상 정기 작업·정상 스크립트는 그대로 둔다.** 같은 폴더에
   있다는 사실은 악성의 근거가 아니다.
5. 배포 기본 정기 작업 열넷도 그대로 둔다.

## 이 위협이 재는 것

- **무엇으로 가르는가.** 설정 조각 둘은 이름·자리·확장자가 같다. 갈라지는
  지점은 **한 줄**이다 — 열쇠 목록을 숨김 폴더로 지정하는 줄. 정기 작업 둘도
  같은 모양이고, 갈라지는 것은 **무엇을 실행하는가** 뿐이다.
- **줄을 뺄 것인가 파일을 치울 것인가.** 앞선 위협 중에는 정상 설정 파일에
  끼어든 줄만 빼야 하는 것이 있었다. 여기는 반대다 — 조각 전체가 검체의
  것이고, 줄 하나만 빼면 나머지 줄이 남는다. **정기 작업도 같다** — 정의
  파일 하나가 통째로 검체의 것이라, 그 안의 줄만 지우면 빈 파일이 남는다.
