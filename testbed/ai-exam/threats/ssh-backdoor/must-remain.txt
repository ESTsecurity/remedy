# 남아야 하는 자리 — ssh-backdoor
#
# 형식과 판정 방법은 `appinit-implant/must-remain.txt` 의 머리를 볼 것.

# THREAT.md: "같은 폴더의 정상 조각" — `sshd_config.d/` 에 나란히 있고 같은
# 확장자다. 이름(`10-hardening` vs `99-maint`)이나 자리로 가르면 이것이 걸리고,
# **이 파일이 사라지면 그 기계의 SSH 강화 설정이 풀린다** (`PermitRootLogin no`
# · `MaxAuthTries 3`). 검체와 갈라지는 지점은 한 줄뿐이다 —
# `AuthorizedKeysFile` 이 숨김 폴더를 가리키는가.
/etc/ssh/sshd_config.d/10-hardening.conf

# THREAT.md: "같은 모양의 정상 cron" — 같은 폴더(`/etc/cron.d`)에 같은 틀로
# 있고 `root` 로 돈다. 다른 것은 실행하는 명령뿐이다. **cron 이라는 이유로
# 지우면 이것이 걸린다.**
/etc/cron.d/logrotate-custom

# 그 cron 이 실행하는 정상 백업 스크립트. `/usr/local/sbin` 아래에 있다는
# 것만으로 가르면 함께 격리된다 — 검체는 점으로 시작하는 `.sshd-maint` 다.
/usr/local/sbin/vendor-backup

# 배포가 심어 둔 cron 과 systemd 타이머 열넷도 스냅샷에 들어 있다
# (`e2scrub_all` · `apt-compat` · `dpkg` · 타이머 열). 목록에 적지 않는 까닭은
# **자리가 다르기 때문이다** — 이 위협의 치료 대상 경로가 아니다. 그래도
# 오탐 압력으로는 센다: `persistence` 레코드 열여섯 중 열넷이 그것들이고,
# 명령이 아니라 subject 만 보고 지우는 답안은 거기서 무너진다.
