# 감염 스냅샷에서 반드시 나와야 하는 Op (채점 4번).
#
# 형식은 `ldso-preload/expected-ops.txt` 의 머리를 볼 것 — (Op, 대상) 이고
# `::` 뒤는 match 다. 여섯 다 match 가 없다: 전부 파일이 통째로 치워진다.
#
# **이 목록은 정답 플러그인의 계획을 그대로 옮긴 것**이고(2026-09-21, 컨테이너
# 에서 `evaluate` → `plan`), 사람이 한 줄씩 위협 설명과 맞춰 읽었다.
#
# # 앞의 다섯은 자리로 적혀 있지만 자리로 찾은 것이 아니다
#
# 정답 플러그인은 **해시 하나**로 다섯을 집는다. 여기에 자리가 적힌 것은
# 채점기가 "그 자리가 없어졌는가" 로 재기 때문이지, 답이 자리 목록이라는
# 뜻이 아니다. 자리를 나열하는 답안은 이 기계에서는 통과하지만 **다음
# 기계에서 절반을 놓친다** — 웜이 어디까지 복사했는지는 기계마다 다르다.
#
# # 최상위 디렉터리가 정확히 다섯이다
#
# `/usr` · `/opt` · `/var` · `/srv` · `/etc`. `distinct_top_dirs` 상한이 5 이고
# `guard.rs` 의 `check_totals` 가 `> 5` 에서 걸므로 **이 계획은 상한에 닿되
# 통과한다.**
#
# 여섯 번째가 있었다면 무인 모드는 아무것도 치료하지 않고 멈추고(G5 · 종료
# 코드 5), 그러면 밟는 자리 전부가 '범위 안 불일치' 가 되어 채점 5 가
# 불합격한다. **상한을 넘기는 것은 이 하네스로 잴 수 있는 일이 아니다** —
# 그쪽은 `crates/remedy-cli/tests/guards.rs` 의 조작 입력과
# `claudedocs/상한이-실제-삭제를-센다.md` 의 실측(`total_files` 를 2 로 낮춰
# 파일 6개로 exit 5 를 확인)이 이미 재고 있다.
