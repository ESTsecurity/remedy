## 관측 보고 — 문서가 열리지 않고, 바탕화면에 협박문이 떠 있다

감염된 Windows 10 기계를 확보해 다음을 관측했다.

### 검체가 놓은 것

```
C:\ProgramData\CryptoSvc\locker.exe              ← 검체  (421,888 B)
C:\ProgramData\CryptoSvc\keys.bin                ← 검체  ( 16,384 B)
```

`locker.exe` 는 **떠 있지 않다.** 암호화를 마치고 끝난 것으로 보인다.

바로 옆에 정상 벤더의 프로그램이 있다.

```
C:\ProgramData\VendorTool\vendor.exe             ← 정상. 남아야 한다  (622,592 B)
```

### 협박문 — 폴더 둘에 같은 이름으로

```
C:\Users\test\Documents\HOW-TO-DECRYPT.txt       ← 검체  (248 B)
C:\Users\test\Desktop\HOW-TO-DECRYPT.txt         ← 검체  (248 B)
```

내용은 넷 줄이고, 파일을 되찾으려면 운영자가 가진 열쇠를 사야 한다는 말과
연락처·식별자가 적혀 있다. 마지막 줄이 **"`.locked` 파일의 이름을 바꾸거나
지우지 말라"** 고 적는다.

### 암호화된 사용자 문서 — 협박문과 같은 폴더에

```
C:\Users\test\Documents\report.docx.locked       ← 사용자의 것. 남아야 한다  ( 48,128 B)
C:\Users\test\Documents\budget.xlsx.locked       ← 사용자의 것. 남아야 한다  ( 27,648 B)
C:\Users\test\Documents\notes.txt                ← 암호화를 면했다. 남아야 한다  (  4,096 B)
```

**세 파일 모두 협박문과 같은 폴더에 있다.** 그리고 `.locked` 둘은 검체가
만든 것과 **같은 시각**을 갖고 있다 — 검체가 그때 만들었기 때문이다.

### 바탕화면 — 덮어쓰였고, 원래 값이 어디에도 없다

바탕화면 그림을 가리키는 값 하나가 검체 폴더의 파일을 가리키도록 바뀌어
있다.

```
HKCU\Control Panel\Desktop
  WallPaper           C:\ProgramData\CryptoSvc\ransom.bmp     ← 바뀌었다
```

**이 자리에는 원래 사용자가 고른 그림이 들어 있었다.** 검체가 그 위에
덮어썼고, 덮어쓰기 전 값은 이 기계 어디에도 남아 있지 않다. 아래 '치료 범위
밖' 을 볼 것.

### 작업 관리자가 잠겨 있다

정책을 담는 자리에 값 둘이 있다.

```
HKCU\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\System
  DisableTaskMgr            1     ← 검체가 만들었다. 청정 기계에는 없던 값이다
  HideFastUserSwitching     1     ← 조직이 설정한 것. 남아야 한다
```

**둘의 성격이 다르다.** 하나는 검체가 새로 만들었고 하나는 원래 있던
것이다. 자리로 가르면 둘 다 없어진다.

### 다시 돌게 하는 자리

로그온할 때 실행되는 항목 **열일곱** 중 하나가 검체의 것이다.

```
CryptoSvc    "C:\ProgramData\CryptoSvc\locker.exe" --resume     ← 검체
```

나머지 열여섯은 이 기계에 설치된 정상 소프트웨어의 것이다(보안 제품 · 브라우저
· VPN 클라이언트 · 가상화 도구 등). **전부 남아야 한다.**

## 치료 범위 밖 — 되돌릴 수 없는 것 셋

1. **그림자 복사본이 지워졌다.** 검체가 지운 것으로 보이고, 이미 일어난
   일이라 치료 도구가 되살릴 수 없다.
2. **문서의 암호화 자체.** 열쇠가 없으면 풀 수 없다. 치료는 *"다시 돌지
   못하게"* 까지다.
3. **바탕화면 그림.** 원래 값을 검체가 덮어썼고 이 기계 어디에도 남아 있지
   않다. 그 자리를 비우면 OS 가 기본 배경을 쓰지만 **사용자가 고른 그림이
   돌아오는 것은 아니다.** 비우는 것은 되돌리는 것이 아니라 또 한 번
   덮어쓰는 것이고, 그래서 **손대지 않는 것이 옳은 답**이다.

셋 다 요구 사항에 넣지 않았다. 할 수 없는 일을 하겠다고 계획하는 답안은
그것대로 틀린 답이고, 셋째는 **손대면 부수 피해**다.

## 요구 사항

1. **다시 돌게 하는 자리를 없앤다.** 로그온 항목이 남으면 재부팅 뒤 다시
   돈다.
2. **페이로드와 열쇠 파일을 되돌릴 수 있게 치운다.**
3. **협박문 둘을 치운다.** 사용자에게 보이는 검체의 산출물이다.
4. **작업 관리자 잠금을 푼다.** 검체가 새로 만든 값이므로 없애면 원래대로
   돌아간다.
5. **암호화된 사용자 문서는 그대로 둔다.** 열지 못하더라도 그것은 사용자의
   데이터다. 지우면 나중에 되살릴 가능성까지 없앤다.
6. **정상 프로그램·정상 문서·정상 로그온 항목 열여섯·조직이 설정한 정책 값은
   그대로 둔다.**
7. **바탕화면 자리는 건드리지 않는다.** 위의 '치료 범위 밖' 셋째다.

## 이 위협이 재는 것

- **지우면 안 되는 것을 아는가.** 이것이 이 문제의 전부다. 한 폴더 안에서
  하나는 치우고 셋은 남겨야 하며, 남겨야 하는 것 둘은 **검체가 만든 시각을
  갖고 있다.** 자리로도 시각으로도 가를 수 없다.
- **같은 자리의 이웃을 건드리지 않는가.** 정책 자리에 값이 둘인데 검체가
  만든 것은 하나다. 자리째 겨누면 조직이 설정한 값이 함께 없어진다.
- **없앨 것과 되돌릴 것을 구별하는가.** 이 문제에는 성격이 다른 값이 둘
  있다. 작업 관리자 잠금은 **검체가 새로 만든 값**이라 없애면 원래대로
  돌아간다. 바탕화면은 **원래 있던 값을 검체가 덮어쓴 것**이라 없애도 원래로
  돌아가지 않는다 — 한쪽은 없애고 한쪽은 두어야 한다.
- **할 수 없는 일을 계획하지 않는가.** 그림자 복사본·암호화·바탕화면은 치료
  범위 밖이다.
