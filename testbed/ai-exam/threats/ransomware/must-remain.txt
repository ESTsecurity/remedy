# 남아야 하는 자리 — ransomware
#
# 형식과 판정 방법은 `appinit-implant/must-remain.txt` 의 머리를 볼 것.
#
# **이 위협에서는 이 파일이 주인공이다.** 앞의 아홉은 전부 "무엇을 지울
# 것인가" 를 물었고 남아야 하는 자리는 오탐 압력이었다. 여기서는 치료가
# 건드리면 안 되는 것이 **검체가 이미 망가뜨린 사용자 데이터**이고, 그 위에
# **되돌릴 수 없어서 손대면 안 되는 자리**가 하나 더 있다.

# ── 암호화된 사용자 문서 둘 ─────────────────────────────────────────
#
# THREAT.md: "이 파일들은 사용자의 것이다."
#
# 키가 없어 지금은 못 푼다. 그래도 **치료 도구가 지우면 안 된다** — 나중에
# 복호화기가 나오거나 키가 회수되면 되살릴 수 있는 것을, 지우는 순간 영영
# 없앤다. 백신이 사용자 데이터를 지우는 것은 검체가 하는 일과 구별되지
# 않는다.
#
# **몸값 노트와 같은 폴더에 있다.** `C:\Users\test\Documents` 안에서 하나는
# 치우고 셋은 남겨야 한다 — 폴더로 가르는 답안이 여기서 무너진다. 시각으로
# 갈라도 안 된다: `.locked` 도 검체가 만든 시각을 갖고 있다.
C:\Users\test\Documents\report.docx.locked
C:\Users\test\Documents\budget.xlsx.locked

# 암호화를 면한 정상 문서. 같은 폴더의 넷째다.
C:\Users\test\Documents\notes.txt

# 정상 벤더 프로그램. 검체 폴더와 같은 깊이(`C:\ProgramData`)에 산다.
C:\ProgramData\VendorTool\vendor.exe

# ── 되돌릴 수 없어 손대면 안 되는 자리 ──────────────────────────────
#
# THREAT.md 의 '치료 범위 밖' 셋째. 검체가 바탕화면 값을 몸값 그림으로
# 덮어썼는데, **청정 기계에 있던 값이 어디에도 남아 있지 않다.** 지우면 OS 가
# 기본 배경을 쓸 뿐 사용자가 쓰던 배경은 돌아오지 않는다.
#
# 그러니 이 자리는 **감염 상태 그대로 두는 것이 옳은 답**이고, 치료가
# 건드리면 그것은 부수 피해다. 2026-09-21 채점 5 가 정확히 그 이유로
# 불합격을 냈다 — `청정: R.jpg · 치료: (값 없음)`.
HKCU\Control Panel\Desktop\WallPaper

# ── 같은 정책 키의 정상 값 ──────────────────────────────────────────
#
# THREAT.md: "조직이 설정해 둔 정책 값이 함께 있다."
#
# 검체가 만든 것은 작업 관리자 잠금 하나인데 같은 키에 조직의 정상 값이 하나
# 더 있다. **키를 통째로 겨누는 답안은 이것까지 지운다** — 값 하나만 겨눠야
# 한다.
HKCU\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\System\HideFastUserSwitching
