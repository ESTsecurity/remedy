# 감염 스냅샷에서 반드시 나와야 하는 Op (채점 4번).
#
# 형식은 `appinit-implant/expected-ops.txt` 의 머리를 볼 것 — (Op, 대상) 이고
# `::` 뒤는 match 다. 여섯 다 match 가 없다: 파일은 통째로 치워지고, 값 둘은
# 통째로 없어진다.
#
# **이 목록은 정답 플러그인의 계획을 그대로 옮긴 것**이고(2026-09-21, 랩 VM
# 스냅샷 위에서 `evaluate` → `plan`), 사람이 한 줄씩 위협 설명과 맞춰 읽었다.
#
# # `registry.delete_value` 가 여기서 처음 밟힌다
#
# 카탈로그의 Op 스물아홉 중 스물셋이 앞의 아홉에서 밟혔다. 남은 여섯 가운데
# 다섯은 **계획 자체가 되지 않는 것**이고(`derive.rs` 의 `NOT_PLANNABLE_YET`
# 넷과 `PLANNED_BUT_GUARDED` 하나), `registry.delete_value` 만이 *"계획은
# 되는데 아직 아무 위협도 밟지 않은"* 자리였다.
#
# # 어느 값에 쓰는 Op 인지를 실기기가 가르쳤다
#
# 처음에는 **바탕화면 값**을 이 Op 으로 지우는 계획이었다. 채점 5 가 그것을
# 불합격으로 냈다 (2026-09-21):
#
#   범위 안 불일치 1건 — HKCU:\Control Panel\Desktop\WallPaper
#     청정: [String] C:\Users\test\Downloads\R.jpg
#     치료: (값 없음)
#
# **청정 기계에 이미 값이 있었고 검체가 그것을 덮어쓴 것**이다. 지우면 OS 가
# 기본 배경을 쓰지만 사용자가 쓰던 배경은 돌아오지 않는다 — 원래 값이 어디에도
# 없다. `registry.delete_value` 는 **검체가 새로 만든 값**에 쓰는 Op 이다.
#
# 작업 관리자 잠금(`DisableTaskMgr`)이 그 자리다. 청정 기계에 없던 값이라
# 지우면 그 자리가 청정 기준과 같아진다. 바탕화면은 치료 대상에서 빼고
# `must-remain.txt` 로 옮겼다 — 건드리면 그것이 부수 피해다.

autorun.remove HKCU\SOFTWARE\Microsoft\Windows\CurrentVersion\Run\CryptoSvc
file.quarantine_only C:\ProgramData\CryptoSvc\keys.bin
file.quarantine_only C:\ProgramData\CryptoSvc\locker.exe
file.quarantine_only C:\Users\test\Desktop\HOW-TO-DECRYPT.txt
file.quarantine_only C:\Users\test\Documents\HOW-TO-DECRYPT.txt
registry.delete_value HKCU\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\System\DisableTaskMgr
