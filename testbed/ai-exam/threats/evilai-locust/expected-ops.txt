# Defender 제외. 하나라도 빠지면 재감염되거나 다음 검체가 그대로 통과한다.

# ── 2026-09-04: Op 이름만 적던 것을 (Op, 대상)으로 조인다 ──────────────
#
# 그전까지 이 파일은 `registry.delete_value` 처럼 **종류만** 적었고, 그것은
# "그 종류가 하나라도 있으면 통과" 를 뜻했다. appinit-r3 회차의 사전 기준에
# 실측으로 적었듯 — AppInit_DLLs 만 지우고 LoadAppInit_DLLs 를 남긴 변형이
# 네 판정을 전부 통과하고 경고도 0이었다.
#
# 개수를 세는 것으로는 부족하다. 그러면 AppInit_DLLs 와 Spooler 를 지운 답이
# 2건으로 통과한다 — 절반짜리 치료보다 나쁜 실패다. 그래서 **대상**을 적는다.
#
# 대상 문자열은 응시자가 아니라 코어가 증거에서 조립한다(`derive.rs`). 룰을
# 어떻게 적었든 같은 레코드를 짚으면 같은 문자열이 나오므로, 답안마다 표기가
# 달라 비교가 무너지지 않는다. `::` 뒤는 `match` 다 — 대상만으로는 구분되지
# 않는 Op 이 있다(`structured_config.remove_key` 는 어느 항목을 빼는가가
# 거기에만 있고, `process.kill` 은 대상 자체가 없다).
