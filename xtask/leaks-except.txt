# 누출 검사의 예외 — `규칙 이름 | 경로 접두사 | 사유`
#
# **여기에는 값이 들어가지 않는다.** 규칙 이름과 경로뿐이라 저장소에 둔다 —
# 공개 저장소의 CI 도 같은 예외로 돌아야 하고, 로컬 파일에 두면 그쪽에서
# 빨개진다. 정확한 값은 `.cargo/leaks.yml`(커밋 안 됨)에 있다.
#
# **예외는 '괜찮다' 가 아니라 '고치면 다시 재야 한다' 는 뜻이다.** 아래 자리는
# 랩 기계에서 **잰 결과**이고, 값을 바꾸면 그것은 더 이상 잰 것이 아니다
# (2026-10-31 결정 7 나). 그래서 넘기고, 넘긴 건수를 검사가 매번 적는다.
#
# 예외를 더할 때: 그 값이 랩 VM 의 것인지(격리 NAT 안의 사설 주소·게스트 이름)
# 아니면 이 PC·사람의 것인지 먼저 가린다. **이 PC·사람의 값은 예외가 아니라
# 빼는 것이 맞다** — 그것은 ③ 에서 뺐다.

# ── 실기기 채점 증거 ────────────────────────────────────────────────

# NAT 주소가 상태 안에 들어 있다. 고치면 증거가 아니게 되고, 다시 재려면
# 위협 20개를 랩 VM 에서 처음부터 돌려야 한다.
Windows 기본 호스트명 | testbed/ai-exam/threats/ | 랩 VM 게스트 이름 — 잰 결과다
